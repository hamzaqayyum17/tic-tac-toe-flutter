# Tic Tac Toe Flutter Game

A Tic Tac Toe game developed using Flutter.

## Features

- Single Player Mode
- Two Player Mode
- X and O turns
- Computer AI
- Scoreboard
- Draw counter
- Restart game
- Game rules screen
- Dark user interface

## Technologies

- Flutter
- Dart
- Material Design
